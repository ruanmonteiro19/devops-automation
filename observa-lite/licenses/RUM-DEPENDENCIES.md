# Digital experience dependencies

The browser SDK and replay UI use rrweb 2.1.7 (MIT) and web-vitals 5.3.0 (Apache-2.0). Package versions and transitive dependencies are pinned by frontend/package-lock.json. Their license texts are distributed in this directory. The Vetra SDK adds its own transport, configuration, consent handling and privacy redaction; it does not bundle Dynatrace proprietary JavaScript.
